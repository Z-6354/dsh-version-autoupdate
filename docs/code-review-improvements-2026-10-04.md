# 代码审阅与修复（2026-10-04）

基线 `37a6d91` / 插件 `0.3.21`。本轮未递增版本、未发布或推送。

## 已修复

- 路由 disposer 通过 Cordis effect 管理，卸载再加载不会保留旧路由。
- 写接口要求 POST，状态接口要求 GET；重复检查与兼容入口在确认空闲后才重置状态，更新期间拒绝重启。
- Node 预检遵循 `^22.19.0 || >=24.0.0`，拒绝 23 和不完整/预发布版本。
- SemVer 解析拒绝非法版本、忽略 build metadata，并正确处理数字与字符串预发布标识。
- 优先读取实际运行 npm、源码或桌面 Host 入口；已知运行位置不可读时返回未知，不冒用其他安装版本。移除机器专用部署路径。
- 安装来源识别支持 Windows 分隔符、npx 和桌面 Host；桌面/npx 不开放全局安装或进程重启。源码可以按平台策略重启，但不能全局安装。
- 安装前查询包管理器全局目录，并核对真实路径，防止升级另一套 DSH；查询失败也阻止安装。
- 重启与离线安装共享 DSH_HOME 路径解析，支持空值回退和波浪号展开。
- 移除旧 client-runtime 类型和 manifest 依赖；直接注册 Widget，保留 Context.effect 的 this 绑定。新增客户端类型检查。
- prepack 自动构建；复制所有顶层 mjs/声明并发布，修复客户端类型入口引用遗漏源码的问题。
- source map 输出为独立文件，使用 indexed map 记录 ModuleLoader 前缀偏移；加载脚本由约 102 KB 减为约 18 KB（其余调试数据保留在 map 中）。
- 锁文件与包版本同步；README 和配置模板与实际默认值同步，通用模板移除部署专用域名。
